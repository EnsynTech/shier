# 主流安全意识 / 钓鱼演练工具：设计调研

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-21 |
| 目的 | 为识饵管理端 UI 提供竞品参照，指导信息架构与视觉，而非逐像素抄袭 |
| 对照产品 | KnowBe4 KSAT、Hoxhunt、Proofpoint PSAT、usecure (uPhish)、Gophish（基线） |

---

## 1. 产品定位差异（决定 UI 学什么）

| 产品 | 管理端气质 | 对识饵的启发 |
|---|---|---|
| **KnowBe4** | 合规 + 内容库 + 可细控；顶栏按业务域划分；仪表盘强调 Risk Score / Phish-prone %；报告一等公民 | 学 **信息架构与指标叙事**；避其界面偏旧、控件密集 |
| **Hoxhunt** | 行为改变、自适应难度、低运维；人因风险看板；建议动作多于手工建活动 | 学 **建议下一步、风险叙事、降低创建摩擦**；不做重度游戏化 |
| **Proofpoint** | 与邮件安全生态绑定；人因/威胁驱动培训；偏企业汇报 | 学 **部门/人群下钻与管理层汇报入口** |
| **usecure** | 顶栏「Create simulation」分步向导；先选攻击类型/模板库；失败后 Inline Training | 学 **场景库驱动的分步创建 + 失败后补训闭环示意** |
| **Gophish** | 侧栏资源 CRUD（模版/页面/配置/组）；创建=巨型 modal | **明确要摆脱的反模式**（识饵现状） |

识饵更接近「乙方顾问操作、向甲方展示」的演练工作台：应 **借 KnowBe4 的域导航与指标，借 Hoxhunt/usecure 的低摩擦创建与跟进，避开 Gophish 资源清单感**。

---

## 2. 共性设计模式（可落地）

### 2.1 导航按业务域，不按底层资源

主流控制台一级入口类似：

- Dashboard / 工作台  
- Phishing 或 Simulations / 演练  
- Users / 人群  
- Reports / 报告  
- （Training 内容库 — 识饵暂以「场景库」替代课程库）

设置、SMTP、Webhook、系统用户放在次级（齿轮 /「设置」），不与主路径平级。

### 2.2 工作台用「组织级风险指标」开场

KnowBe4 以 **Risk Score**、**Phish-prone Percentage（易中招率）**、行业对标、近月趋势小窗为主。  
Hoxhunt 强调人因风险与行为趋势，而不是「打开/点击饼图墙」。

识饵应对齐为：

1. 一个主指标（如近 30 天易中招率 / 点击率）  
2. 趋势与简短结论句  
3. 进行中演练 + 建议下一步  
4. 部门对比（已有能力）

### 2.3 创建是「整页分步向导」，不是弹窗

KnowBe4：`Phishing → Create Campaign` 独立页。  
usecure：`uPhish → Create simulation`，先选攻击类型/落地页/邮件模板，再选人与排期，最后可挂 Inline Training。

识饵已定场景驱动四步向导；调研强化两点：

- 步骤指示放在 **页顶横向**（行业更常见）  
- 失败后补训 / 跟进在结果页显式出现（即使首期只做标记与导出）

### 2.4 报告是一级入口

KnowBe4 将 Reports 做成卡片目录 + CSV/PDF + Download Center，服务高管与审计。  
识饵乙方场景更需要 **「管理层简报」一键入口**，不宜只藏在单场结果页按钮里。

### 2.5 结果页：先失败人群，再原始事件

竞品活动详情普遍突出：易中招率、失败用户列表、失败类型（点击/提交/打开附件等），再导出。  
地图、原始事件流降权 — 与识饵 `ui-design.md` 已定阅读顺序一致。

## 3. 应避免的模式

| 模式 | 来源 | 原因 |
|---|---|---|
| 侧栏平铺模版/页面/SMTP/组 | Gophish | 强迫用户理解实现细节才能开演练 |
| 单 modal 填完全部字段 | Gophish | 无法承载场景库、多通道、多步骤 |
| 开发工具式极窄图标轨 | 部分现代 SaaS | 与甲方培训/安全运营心智不符；标签可发现性差 |
| 仪表盘堆满等大饼图 | 旧版钓鱼工具 | 无结论、难汇报 |
| 为抄 KnowBe4 而蓝白密集表格 | KnowBe4 观感 | 与已批准「轻量定制」冲突 |

---

## 4. 对识饵设计的直接决议

1. **壳层**：浅色顶栏 + 业务域文字导航 + 右侧「发起演练」主按钮；设置收入「设置」菜单。  
2. **一级导航**：工作台 · 演练 · 场景库 · 人群 · 报告。  
3. **工作台英雄区**：易中招率（主指标）+ 一句话态势 + 建议动作；次级为进行中演练与部门表。  
4. **向导**：整页、顶栏步骤条；场景库第一步。  
5. **报告**：独立页，提供简报卡片与导出示意（对接 P3）。  
6. **视觉**：保留苔藓绿轻量定制，不用 KnowBe4 蓝、不用深色图标轨作为默认壳。

详见更新后的 `docs/ui-design.md` 与 `docs/ui-redesign-demo.html`。
